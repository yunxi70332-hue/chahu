## 一、决策记录(2026-09-15 拍板)

| # | 问题 | 决策 | 对系统的影响 |
| --- | --- | --- | --- |
| 1 | 报单审核后资金怎么处理 | **回收模式,平台打款**:审核通过 = 余额**增加** 本金(货款)+ 佣金 | 资金方向反转,删除"余额不足拦截";提现=管理员线下转账后后台记账扣余额,不做提现审批流 |
| 2 | 佣金怎么算 | **品类比例自动算 + 单笔可手动改** | 新增品类佣金比例设置;报单时自动算出佣金,可覆盖 |
| 3 | 报价表怎么进系统 | **V1 就做 Excel 一键导入** | 后端解析 xlsx 整批替换产品库;历史报单靠快照字段不受影响 |
| 4 | 会员端是否后置 | **会员端也要(进 V1)** | 会员登录同一套系统:自助报单 + 查自己的单/流水;按角色出菜单,不做独立前台 |
| 5 | 异常报价(≤0/空/"待核对") | **默认隐藏** | 导入时即置为下架;报单选品搜不到;产品管理页可见可核对 |
| 6 | 代理人货款怎么提走 | **平台打款 + 线下提现** | 审单自动加钱;管理员在用户页做"提现"操作扣余额并记流水 |

### 资金模型 v2.1(与 v2.0 相反)

```
代理人提交报单 ──► 管理员审核通过
                     │
        平台打款:余额 += 本金(总额)      → 流水[报单打款 +]
                 余额 += 佣金(比例自动算) → 流水[佣金 +](>0 时)
                     │
        代理人余额累积 ──► 申请提现(线下)
                     │
        管理员记提现:余额 -= 提现金额    → 流水[提现 -]
```

- 不存在"余额不足拦截"(打款方是平台)。
- 手动"补款"(+)用于线下特殊打款 correction;"调整"(±)用于纠错,均必填备注。
