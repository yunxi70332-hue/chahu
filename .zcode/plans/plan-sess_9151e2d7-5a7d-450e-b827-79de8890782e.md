# 用户管理:双击「已实名」徽章查看实名信息快照

## 现状结论(已探索确认)
- 后端**零改动**:管理端接口已存在 —— `GET /api/realname/:userId`(`backend/src/routes/realname.js:128`,仅 ADMIN,返回完整证件号)和 `GET /api/realname/:userId/photo`(照片流)。前端 API 封装 `getRealnameDetail` / `fetchRealnamePhoto` 已齐全。
- `RealnameReviewDialog.vue` 已实现完整展示:左侧身份证照片(blob 加载 + 点击放大)、右侧信息描述列表(状态/姓名/手机号/真实姓名/身份证号/提交时间/审核时间),对非 PENDING 状态已有只读兜底(隐藏通过/驳回按钮)。

## 实现方案(纯前端,2 个文件)

### 1. `frontend/src/views/users/components/RealnameReviewDialog.vue` — 增加只读模式
- props 增加 `viewOnly?: boolean`(默认 false,不影响现有审核入口)。
- 标题:`viewOnly` 时显示 `实名信息快照 - {姓名}`,否则保持 `实名审核 - {姓名}`。
- footer:`viewOnly` 时隐藏「重置实名」按钮,只保留「关闭」。
- 只读提示文案:`viewOnly` 时显示「实名信息快照,仅供查看」。

### 2. `frontend/src/views/users/Users.vue` — 实名列加双击
- 新增 `snapshotVisible` / `snapshotUserId` 状态和 `openSnapshot(row)`。
- 实名列中「已实名」的 `el-tag` 加 `@dblclick="openSnapshot(row)"`(仅 ADMIN 生效),加 `cursor: pointer` 样式提示可交互。
- 注册第二个只读弹窗实例:`<RealnameReviewDialog v-model="snapshotVisible" :user-id="snapshotUserId" view-only />`,与现有审核弹窗互不干扰。

范围:按需求仅「已实名」徽章支持双击;待审核已有「实名审核」入口、已驳回已有悬浮驳回原因提示,不扩展。
