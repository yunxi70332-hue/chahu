## Ardot 画布排坑经验（重要，复用）
1. **卡片固定高度会裁剪图表**：容器 `clipsContent:true` + 父卡固定 height，子图表超高时表现为「左侧/下半部分内容无故消失」（实际是垂直裁剪，矮的元素整根被裁掉）。症状像渲染 bug，实为布局问题。修法：父卡 height 改 `hug_contents`。本次趋势卡 2:109 height=100 裁掉了 y>55 的所有柱子和全部日期。
2. **大幅面 SVG（宽>~250）渲染残缺**：`transform rotate`、`stroke-dasharray`、多段 path/polyline 不可靠；可靠原语只有 rect、circle、A 弧 path、text。饼图用 A 弧成功；柱图/折线超宽时用**原生节点**（layout:none 容器 + 绝对定位 frame 柱子）最稳。
3. **U() 改 svg 属性静默失败**：已插入的 SVG 节点想换 svg 内容，U 不会生效（截图逐字节相同），须 D 旧 + I 新。
4. **C() 非组件复制时 descendants 映射失效**（"Copy descendant not found"）：复制后 batch_read 拿新 id 再逐个 U()。
5. **flexbox 未实现**：`fill_container(620)` 带 minWidth 报错 set-minWidth not implemented，用固定宽度。
6. **截图下载**：Windows Git Bash 下 curl 到 /tmp 失败，用 `$TEMP`；capture_screenshot 返回 URL 须 curl 下载后用 Read 读图验证。
7. **capture_layout 默认 problemsOnly=true**，要拿全量节点需显式传 `problemsOnly:false`。
